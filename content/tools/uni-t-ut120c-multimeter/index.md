A delightfully compact multimeter that does everything you'd expect one to do. For me that's continuity, AC/DC voltage, and occasionally resistance. It doesn't have a backlight, but it does have a proper beeper for continutity checking!

{{ figure(width=640, path="tools/uni-t-ut120c-multimeter/it.jpeg") }}

The probes don't detach - I might print some kind of clip/pointy end cap thing at some point as it's easy to poke yourself when rummaging for it in a tiny toolkit.

Bear in mind when purchasing - there are 3 models, UT120A, B and C - the "C" is the most capable one, notably the others can't do current measurement.
